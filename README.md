# Hydroeletric Services

Projeto acadêmico desenvolvido no SENAI com o objetivo de criar um site institucional para uma empresa de Instalações Hidráulicas e Elétricas Prediais.

## 🎯 Objetivo

Criar um site institucional moderno e organizado para representar uma empresa de vendas de produtos de Instalações Hidráulicas e Elétricas Prediais, destacando seus produtos, gerenciamento e interface visual.

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- MySQL
- Git
- PHP

## 📌 Funcionalidades do Site

- Página inicial (Home)
- Produtos em Destaque
- Categorias de Produtos
- Filtrar Materiais por Nome
- Área de Contato
- Catálogo de Produtos
- Cadastro de Produtos
- Área de Cadastro de Usuário
- Área de Login
- Área Exclusiva para o Administrador

## 💡 Conceitos Aplicados

- Estrutura semântica em HTML
- Organização de pastas
- Estilização com CSS
- Identidade visual consistente
- Lógica feita com PHP
- Modelagem de Banco de Dados
- Banco de dados feito com MySQL
